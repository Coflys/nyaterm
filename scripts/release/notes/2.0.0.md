# NyaTerm 2.0.0

NyaTerm moves from Tauri to a native GPUI Rust desktop workspace. RDP, VNC and MCP helpers are included with the application. Stable keeps the existing application identity and `.nyaterm` data directory; Preview remains separate.

## 升级必读

- 升级前退出应用，备份完整数据目录及密钥；便携版请备份整个程序目录。
- **Windows 1.x 便携版必须手动升级**：下载同架构完整 ZIP，覆盖全部程序文件，保留旧 `data/` 和密钥。必须复制 RDP/VNC helper、MCP 及 ConPTY，不能只替换 `NyaTerm.exe`。旧内置更新器不支持此次迁移。
- **旧 MSI 用户手动迁移**：备份后卸载旧 MSI，再安装同架构 NSIS `-setup.exe`，不要删除用户数据。
- Preview 用户导出 `.nya` 备份并在 Stable 恢复；两者数据目录不会自动合并。
- 升级失败时恢复迁移前完整副本，不要用旧程序打开新版已写入的数据。
- Windows 10/11；不支持 Windows 7。使用与设备匹配的架构。

[完整迁移指南](https://nyaterm.app/docs/getting-started/migration-v2)

## Upgrade instructions

- Quit and back up the complete data directory and key files before upgrading. Back up the whole directory for portable installations.
- **Windows 1.x portable builds require a manual upgrade**: extract the complete same-architecture ZIP, replace all program files, and preserve existing `data/` and keys. Include RDP/VNC helpers, MCP, and ConPTY; do not replace only `NyaTerm.exe`. The old updater cannot perform this migration.
- **Old MSI installations require manual migration**: back up, uninstall the MSI without removing user data, then install the same-architecture NSIS `-setup.exe`.
- Export a `.nya` backup from Preview and restore it in Stable; their directories are not merged automatically.
- Recover using the complete pre-migration copy. Do not open data written by the new application with an old executable.
- Windows 10/11 is required; Windows 7 is unsupported. Match the package architecture to your device.

[Full migration guide](https://nyaterm.app/en/docs/getting-started/migration-v2)
